칸별 결과 평가와 채점 범위

입력 규칙·모델·학습 참조를 합친 최종 표시값을 채점합니다. 상세 칸은 매뉴얼 규칙으로 정답을 분해할 수 있는 일부 행만 평가합니다. 지정값 정확도는 미지정 표기(-, -- 등)를 정답에서 제외해 계산합니다. 이 비율을 전체 원재료나 순수 학습 모델의 정확도로 해석하면 안 됩니다.

후보 개수 K에 따른 정답 포함률

K=5는 앞의 후보 5개 중 정답 코드가 하나라도 있으면 해당 행을 맞힌 것으로 셉니다. 그룹별 전체 행 수를 고정해 계산하며, 정답 원문과 완전히 같은 코드인지 비교합니다.

후보 스펙트럼 평가

완성 코드 일치는 확정 여부와 관계없이 여섯 칸 값을 품목별 위치에 조립해 비교한 진단 지표입니다. 등록 코드 검색과 모델 예측을 구분합니다. 운영용 등록 마스터를 제외한 학습 참조로 최종 코드 일치를 평가합니다.

02

코드 후보 확인

완성 코드와 후보 순위를 확인하세요. 후보를 선택하면 해당 코드의 근거와 검증 상태가 표시됩니다.

03

Vendor 단서 확인

입력의 제조사 단서를 품목별 코드표와 대조합니다. SAMYANG과 PANJIT처럼 여러 제조사가 등장하면 각각의 근거를 보존하고 검토를 요청합니다.

04

완성 코드는 별도 결과

등록 코드 후보는 실제 문자열과 길이를 유지합니다. 모델 코드는 확인된 구간 규칙을 만족할 때만 조합합니다. 자동 확정은 등록 품목명과 규격명이 정규화 후 일치하는 기존 코드에만 표시합니다. ERP의 ‘-’와 ‘--’는 유효한 값이며, 확인 필요 상태를 뜻하지 않습니다.

점수의 의미

모델로 고른 값은 보정하지 않은 모델 점수를 표시합니다. 등록 코드나 입력 규칙에서 읽은 값은 근거 종류를 표시합니다. 품번은 두 랭커의 평균 순위를 표시하며, 낮을수록 좋습니다. 두 종류의 점수를 서로 비교하지 마세요.

예측 코드는 자동 확정 여부와 관계없이 표시됩니다. 자동 검증을 통과하지 않은 칸은 검토 권장으로 구분합니다. 분류 칸은 코드의 실제 분류 구간값입니다. 품목군과 다르며, 규칙이 미확인된 코드의 구간을 임의로 추측하지 않습니다.
